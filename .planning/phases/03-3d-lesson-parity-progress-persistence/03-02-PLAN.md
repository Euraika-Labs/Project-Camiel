<objective>
Build the three reusable pieces every one of the five lessons is assembled from, and prove the
order-enforcement mechanism before a single lesson exists.

The one decision this plan settles for the whole phase: **D-46 versus D-44 is resolved by
parametrizing the total, not by reshaping lesson 5.** D-46 asks that one progress-label form cover
every lesson; D-44 makes lesson 5 a genuine four-step sequence. Treating those four steps as three
scored sub-tasks would misreport lesson 5's actual rule to the child and to any probe asserting
step count, so this plan keeps all four steps and puts the label form in exactly one place:
`set_step(current, total)` inside `scripts/ui/lesson_hud.gd`, which builds `Stap: %d / %d`. Lessons
1 through 4 pass a total of 3 and lesson 5 passes 4. That is the most literal possible reading of
D-46 — one form, one file, one call shape in all five orchestrators — while staying correct for
the four-step lesson. Research recommended parametrizing the total; this plan adopts that and adds
the constraint that the format string exists once in the repository, which an acceptance criterion
counts.

D-37 is the other thing this plan makes real. The archived shape lesson declared an
expected-order array and never read it, so a child could touch the shapes in any order and the
lesson congratulated them. The fix is not a better check — it is removing the possibility: an
inactive target has no code path that reaches completion, and it announces a refusal through its
own signal so a probe can assert the negative directly. This plan proves that mechanism in
isolation, on a real floor with the real character body, before any lesson depends on it.

Purpose: this plan and plan 03-01 are the phase's foundation and touch no file in common. Nothing
in LESSON-01 through LESSON-05 can be built until the target, the room and the display exist.

Output: `scripts/lesson_target.gd` and `scenes/lesson_target.tscn`, `scenes/lesson_room.tscn`,
`scripts/ui/lesson_hud.gd` and `scenes/ui/lesson_hud.tscn`, and
`scripts/tools/probe_lesson_kit.gd`.

Decisions implemented: D-34, D-35, D-37, D-38, D-45, D-46.
</objective>
