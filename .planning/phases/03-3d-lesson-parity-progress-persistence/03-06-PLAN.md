<objective>
Close the phase the way phases 1 and 2 closed: run every automated claim on the finished tree, put
the real game in front of a person, and prove the one thing a headless probe structurally cannot.

Two things in this phase's scope are invisible to the check that guards it. The first is whether a
three-year-old can actually do these five lessons — whether the targets are far enough apart to not
be hit by accident and close enough to reach, whether a refused shape reads as "not yet" rather than
"broken", and whether three objects read as three things to gather. The second is whether progress
survives a real process exit: every probe writes and reads inside one process, so no probe can prove
the file outlives the program. After the user quits, a separate fresh engine process loads the file
their session wrote and reports what it found. That is a second-process proof, and Claude runs it —
the user is not asked to read a file.

Purpose: the last gate before verification. It closes the manual-only rows in this phase's
validation strategy and produces the tuned tree the phase ships.

Output: `.planning/phases/03-3d-lesson-parity-progress-persistence/03-06-SUMMARY.md`, plus whatever
value changes the verdict calls for.

Decisions honoured: every locked decision from D-31 through D-46 as already built; this plan changes
none of them.
</objective>

Each lesson drops you into a square 12-metre room with four walls, its own title at the top left and

  blue, and one only when all three balls are gathered.
- **Les 2** has a circle, a square and a triangle, all the same orange. Only the one that is your
  turn glows; the other two are dull. Touch them in the order circle, square, triangle.
- **Les 3** has three blue discs numbered 1, 2 and 3. Same idea, in number order.
- **Les 4** has a yellow box, a green box and three balls of a third colour. Any order, like Les 1.
- **Les 5** has four discs numbered 1 to 4, and its counter reads out of four rather than three.

       before touching red or blue. Expected: the counter stays at `Stap: 0 / 3` for the first two

    7. Play `Les 4` in any order you like, and `Les 5` in number order 1, 2, 3, 4. Expected: `Les 5`'s
