1. Existing-install guard. If `/Applications/Godot.app` exists, run `/Applications/Godot.app/Contents/MacOS/Godot --version`.
   - Output starts with `4.7.2.stable`: skip to step 5.
   - Any other version: STOP and ask the user before replacing anything. Never overwrite a different Godot install silently.
2. Download over HTTPS into a `mktemp -d` work directory, with `curl --fail --location --retry 3`:
   - `https://github.com/godotengine/godot-builds/releases/download/4.7.2-stable/Godot_v4.7.2-stable_macos.universal.zip`
   - `https://github.com/godotengine/godot-builds/releases/download/4.7.2-stable/SHA512-SUMS.txt`
   - Both assets were confirmed to exist in that release at planning time.
3. Integrity check.
   - EXPECTED is the first field of the SHA512-SUMS.txt line whose filename field is `Godot_v4.7.2-stable_macos.universal.zip`.
   - ACTUAL is the first field of `shasum -a 512` over the downloaded zip.
   - Require EXPECTED to be non-empty and equal to ACTUAL. Otherwise delete the download and stop.
4. Extract with `ditto -x -k` into the work directory, which preserves the bundle signature. Copy the single `.app` bundle it contains (expected name `Godot.app`) to `/Applications/Godot.app` with `ditto`.
5. Signature check. `codesign --verify --deep --strict /Applications/Godot.app` must exit 0.
   - Record the `TeamIdentifier` line from `codesign -dv /Applications/Godot.app 2>&1` in the SUMMARY.
   - Record the output of `spctl --assess --type execute /Applications/Godot.app`, for information only.
   - Never remove quarantine attributes and never change Gatekeeper settings.
6. Run `/Applications/Godot.app/Contents/MacOS/Godot --version` and record the full string. Delete the work directory.
7. Do not edit shell profiles or PATH. The headless check in Plan 01-03 finds this path itself.
