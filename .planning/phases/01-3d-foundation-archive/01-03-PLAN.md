<objective>
Tracer first. Prove the architecture end to end with Godot 4.7.2 running headless: a Compatibility-renderer project with Jolt physics boots a Node3D main scene, and one command imports, runs, verifies, and reports green, or red for a planted script error (FOUND-03, FOUND-04, FOUND-06). The 2D-era smoke test passed despite a real parse error, so this check must be proven to fail as well as pass (D-09). Output: an engine-written project.godot, `scenes/test_space.tscn`, `assets/materials/ground.tres`, `scripts/tools/verify_3d_project.gd`, `scripts/tools/run_headless_check.sh`, `scripts/tools/test_headless_check.sh`, and the `.gitignore` fix.

Decisions implemented: D-01, D-02, D-03, D-04, D-07 (guard), D-09. The physics engine choice is Jolt, per Claude's Discretion. Reason: Jolt is built into the engine and is the default for new projects since 4.6, and there is no legacy 3D physics to preserve.
